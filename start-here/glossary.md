# NeuroAI glossary / NeuroAI 术语表

[Home](../README.md) · [Start here](README.md) · [Learn](../learn/README.md) · [Topics](../topics/README.md) · [Resources](../resources/README.md) · [Projects](../projects/README.md) · [Community](../community/README.md)

These terms have different meanings across neuroscience, machine learning, and cognitive science. Use the paper's operational definition when it gives one; the short descriptions below are orientation, not universal definitions.

| Term | 中文 | How to read it across fields |
| --- | --- | --- |
| Neuron | 神经元；人工神经元 | In neuroscience, a neuron is a biological cell with complex electrical and biochemical processes. In an artificial network, a “neuron” is a computational unit defined by a mathematical operation. Shared vocabulary does not mean the units are mechanistically equivalent. |
| Representation | 表征；表示 | In neuroscience, this can mean the structure of neural activity associated with stimuli, actions, or latent variables. In machine learning, it often means a model's internal features or activations. Ask what is represented, in which measured or modeled variables, and by what comparison. |
| Prediction | 预测 | It may mean a model's estimate of a future or missing observation, an output used to guide behavior, a neural prediction in a theory, or a statistical forecast. Check the target, time point, and role of the prediction. |
| Learning | 学习 | In machine learning, learning usually means changing model parameters or state from data or feedback. In neuroscience and psychology it can refer to behavioral change, plasticity, or a proposed underlying mechanism. A learning curve alone does not identify the mechanism. |
| Inference | 推断；推理 | In statistics and machine learning, inference often means estimating unknown variables or parameters from observations after a model is specified. In cognitive science, it may refer to a process attributed to an agent. In neural modeling, clarify whether it is computation within a model, parameter estimation, or a claim about the brain. |
| Objective | 目标函数；优化目标 | An objective specifies what a model is trained to minimize or maximize, such as prediction error or reward. In neuroscience it may also refer to a proposed goal of an organism or a normative account. A model's training objective is not automatically the brain's objective. |
| Optimizer | 优化器 | An optimizer is a procedure for changing model parameters to improve an objective, such as gradient descent. It is distinct from the objective itself and from the neural mechanism that a model may be intended to explain. |
| Learning rule | 学习规则 | A specification of how parameters or synaptic strengths change and which signals are required. When reading a gradient-based method, distinguish generating a credit signal from applying an optimizer's parameter update. Record any explicitly specified objective and assumptions. |
| Encoding | 编码；编码模型 | An encoding model maps stimulus, task, or behavioral variables to measured neural responses. “Encoding” can also refer more broadly to how information is carried. Check the variables, direction of prediction, and whether the model is descriptive or mechanistic. |
| Decoding | 解码；解码模型 | A decoding model predicts a stimulus, task variable, or behavior from neural activity. Successful decoding shows that information useful for that prediction is present under the analysis; it does not alone show that the brain reads out the signal in that way. |
| Credit assignment | 信用分配 | In learning, this is the problem of determining which parameters, actions, or neural elements contributed to an outcome or error. A proposed learning rule must specify what signals are available and how responsibility is assigned. |
| Representational similarity analysis (RSA) | 表征相似性分析 | Compares the relationships among matching experimental conditions or stimuli in different systems, often through representational dissimilarity matrices. Check stimulus order, distance measure, reliability, and what is held out for evaluation. |
| Predictive coding | 预测编码 | A family of models describing computation through predictions and residual errors. Specify what the variables represent, how activity is inferred, and how weights are learned; different models use different assumptions. |
| Meta-learning | 元学习 | Learning across tasks to support adaptation to a new task. Identify what changes within a task and what changes across tasks: adaptation may involve network activity, parameter updates, or both. |
| Spiking neural network (SNN) | 脉冲神经网络 | A network whose modeled neurons communicate through discrete spike events. The spike representation and dynamics do not by themselves specify how the network learns. |
| Spike-timing-dependent plasticity (STDP) | 脉冲时序依赖可塑性 | Plasticity associated with the relative timing of presynaptic and postsynaptic spikes. A model may also depend on voltage, firing history, or homeostatic variables; read the actual rule in [Learning rules and predictive coding](../topics/README.md#learning-rules-and-predictive-coding). |
| Generalization | 泛化 | Performance on inputs or conditions beyond those used for fitting or training. The relevant notion depends on the held-out split: new examples, sessions, tasks, environments, or subjects test different kinds of transfer. |
| Continual learning | 持续学习 | Learning from a sequence of experiences while retaining earlier abilities. Specify the sequence, memory budget, task boundaries, and information available at test time; [generalization and adaptation](../topics/README.md#generalization-and-adaptation) links contrasting approaches. |
| Reinforcement learning | 强化学习 | Learning to act using reward feedback under a specified task and interaction protocol. Distinguish observed rewards, estimated values or returns, and the signals used to update a policy or model; see the [learning materials](../learn/README.md#reinforcement-learning-and-cognitive-modeling). |
| Dynamical system | 动力系统 | A model specifying how a state changes over time, continuously or in discrete steps. Identify the state variables, inputs, evolution rule, and measured outputs before interpreting a trajectory. See [neural dynamics](../topics/README.md#neural-dynamics-and-circuit-computation). |
| Latent state | 潜在状态；隐状态 | An unobserved variable in a model, inferred from observations. A latent trajectory depends on the model and its coordinate choices; compare predictive performance as well as plots in the [population-model project](../projects/README.md#compare-latent-neural-trajectories). |
| Neuromorphic computing | 神经形态计算 | Computing systems designed using selected neural principles, often involving event-driven computation. State which principles, software or hardware, workload, and measurements are involved; a spike-based model alone does not specify its hardware efficiency. |
| Mechanism | 机制 | A mechanism is an account of the parts and operations that produce an observed result. A model can be a useful functional description without being a verified biological mechanism. |

For a first paper, record the authors' definitions and distinguish mathematical assumptions, computational results, behavioral evidence, and neural evidence. The [learning pathways](pathways.md) and [Chinese guide](README.zh-CN.md) offer ways to practice this distinction.
