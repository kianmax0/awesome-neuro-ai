# NeuroAI 中文入门指南

[Home](../README.md) · [Start here](README.md) · [Learn](../learn/README.md) · [Topics](../topics/README.md) · [Resources](../resources/README.md) · [Projects](../projects/README.md) · [Community](../community/README.md)

NeuroAI 把神经科学与人工智能放在一起研究：神经科学可以帮助我们提出关于智能计算的新问题，人工模型也可以帮助我们检验关于脑活动和行为的假设。模型能预测脑活动，并不等于大脑一定采用了同一种机制。

你可以不写代码就开始：看一场 [NeuroAI 公开讲座](../learn/README.md#public-lectures)，从 [Learn 中的 Brain Facts](../learn/README.md#neuroscience-and-modeling-textbooks)认识基本概念，或听一场[研究对话](../community/README.md#conferences-and-research-conversations)。先尝试用自己的话解释一个大脑与 AI 之间的联系。想进一步读论文时，再记录研究测量了什么、模型做了什么、证据支持什么结论。[术语表](glossary.md)解释了跨领域容易混淆的词；[学习路径](pathways.md)帮助你按已有背景选择路线。

## 建议的学习方法

不必按固定顺序读完所有材料。先从最接近自己兴趣的问题开始；缺少生物学背景时，可读[神经科学与建模教材](../learn/README.md#neuroscience-and-modeling-textbooks)中的入门材料；需要编程或数学时，再按需查看[编程与数学](../learn/README.md#programming-and-mathematics)。已经熟悉这些内容，就直接从[课程](../learn/README.md#courses-and-tutorials)或某个研究主题开始。

阅读论文时，分别记录研究问题、任务、模型、比较对象、数据和评价指标。再区分综述观点、数学结果、计算实验、行为证据和神经数据证据。结果支持的范围取决于具体比较条件；相似的表现或表征本身不能证明大脑使用该模型的机制。

## 可以完成的小项目

- **不写代码：比较论文和图表。** 从[项目指南](../projects/README.md#compare-a-paper-and-its-figures)选一篇论文，用表格整理问题、测量、模型和证据。
- **比较模型表征。** 用相同输入和顺序生成两张表征差异矩阵；只比较对应的上三角非对角元素，不要把对称矩阵的重复项再次计入。步骤见[模型表征比较](../projects/README.md#compare-model-representations)。
- **继续实践。** 研究者可尝试[认知任务与循环网络比较](../projects/README.md#compare-models-on-a-cognitive-task)或[脉冲机制练习](../projects/README.md#inspect-a-spiking-mechanism)；这些是练习建议，本仓库没有声称已运行官方示例或复现实验。
- **研究时间与适应。** 用[顺序学习练习](../projects/README.md#test-sequential-learning)同时记录新任务学习与旧任务保持，或用[潜在神经轨迹比较](../projects/README.md#compare-latent-neural-trajectories)检验群体模型对留出数据的预测。
