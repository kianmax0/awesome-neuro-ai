## Start here

- **New to NeuroAI:** Read the [reviews and foundations](learn/README.md#reviews-and-foundations), then choose a [course](learn/README.md#courses-and-tutorials).
- **Comparing AI with brains:** Explore [comparison methods and papers](research/README.md#comparing-brains-and-models), then inspect a [benchmark](practice/README.md#benchmarks).
- **Studying learning or cognition:** Choose a [research theme](research/README.md), then find a suitable [tool or task](practice/README.md#tools-and-environments).
- **Ready for a small exercise:** Follow the [Chinese beginner guide](docs/getting-started.zh-CN.md), which includes a learning route, a representation-comparison exercise, and a glossary.

## Repository layout

```text
awesome-neuro-ai/
├── README.md                    # Start here: overview and navigation
├── learn/README.md              # Reviews, foundations, and courses
├── research/README.md           # Papers grouped by research question
├── practice/README.md           # Tools, datasets, and benchmarks
├── community/README.md          # Related reading and training collections
├── docs/
│   ├── getting-started.zh-CN.md  # Chinese learning guide and glossary
│   └── curation.md              # Selection history and maintenance process
├── CONTRIBUTING.md              # How and where to suggest a resource
└── .github/                     # Contribution templates and link checks
```

Each resource has one main entry on its subject page. The pages explain who they are for, where to begin, and what each section covers.

## Contributing

Suggest resources or corrections through an issue or pull request. Include an original source, a short explanation of its NeuroAI relevance, and any access or maintenance limitations. Read the [contribution guidelines](CONTRIBUTING.md) and [curation notes](docs/curation.md).
