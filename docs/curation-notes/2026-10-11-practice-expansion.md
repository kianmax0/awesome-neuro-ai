# Practical and community expansion: 2026-10-11

## Review scope

Added eight practical resources and three community resources. The nine existing practice entries and three existing community entries retain their descriptions and URLs. Existing section anchors and access or legacy caveats remain. The new introductions route first-time builders toward documented examples and experienced readers toward measurement-led evaluation.

This review inspected official documentation, project sites, maintainer repositories, and selected software metadata. It did not install software, execute notebooks, download datasets, reproduce results, or submit to a benchmark. Resource selection and the proposed reading routes are editorial judgments. No claim of installation compatibility, performance, or biological validity follows from inclusion.

## Practical additions and primary evidence

| Resource / type | Why include it and what was verified | Access, licensing, and remaining limits |
| --- | --- | --- |
| Brian 2 / simulator | Adds equation-based mechanistic experiments alongside the existing SNN training frameworks. Official [documentation](https://brian2.readthedocs.io/en/stable/) links tutorials, examples, neuron equations, synapses, and compatibility guidance. [Maintainer metadata](https://github.com/brian-team/brian2/blob/master/pyproject.toml) specifies numerical dependencies and CeCILL-2.1 licensing. | Development-branch dependencies need not match a released version; readers should use release-specific documentation. Browser demos depend on Binder availability. No example was executed. |
| Tonic / data library | Adds event-based input preparation rather than another general ML framework. Official [documentation](https://tonic.readthedocs.io/en/latest/) includes N-MNIST, event transformations, batching, and vision/audio datasets. [Maintainer metadata](https://github.com/neuromorphs/tonic/blob/develop/pyproject.toml) lists GPL-3.0-only and numerical/audio dependencies. | Dataset licenses remain separate. The development branch pins optional Torch packages and limits NumPy; no cross-library environment was validated. Latest docs may describe development code. |
| rsatoolbox / analysis library | Makes brain–model representational comparison actionable. Official [documentation](https://rsatoolbox.readthedocs.io/en/stable/) covers dissimilarity estimation, model comparison, noise ceilings, bootstrap/cross-validation inference, and modality demos. [Maintainer metadata](https://github.com/rsagroup/rsatoolbox/blob/main/pyproject.toml) specifies MIT licensing, Python requirements, and optional imaging dependencies. | Methods require an appropriate experimental design and uncertainty treatment; similarity is not evidence of a shared mechanism. Dependencies were inspected, not installed. |
| CEBRA / embedding library | Complements latent-model benchmarks with neural–behavioral embedding workflows. Official [documentation](https://cebra.ai/docs/) describes PyTorch methods, API-version caveats, version-dependent licensing, and patents; its [demo index](https://cebra.ai/docs/demos.html) includes hippocampus, visual cortex, decoding, cross-animal alignment, and DANDI examples. | Source versions from 0.4.0 use Apache 2.0; versions 0.1.0–0.3.1 have academic-use terms. Demo notebooks need their datasets and sometimes extra environments. No patent interpretation or runtime validation was performed. |
| THINGS-data / dataset collection | Adds behavioral similarity and temporally resolved human responses to the visual data choices. The author [project site](https://vicco-group.github.io/THINGS-data/) distinguishes raw fMRI/MEG, derivatives, behavior, and encoding/RSA examples; the [analysis repository](https://github.com/ViCCo-Group/THINGS-data) is distinct from the data hosts. | The [THINGS initiative](https://things-initiative.org/) states original stimulus-image academic-use restrictions and identifies a separate license-free THINGSplus subset. Open neural data do not imply unrestricted stimulus-image reuse. Exact trial/image counts are omitted because the initiative page contains differing counts. |
| DANDI Archive / portal | Offers discovery beyond a small fixed list and links to FALCON recordings. Official [archive documentation](https://docs.dandiarchive.org/) includes search, NWB, streaming, and example Dandisets; [license guidance](https://docs.dandiarchive.org/user-guide-sharing/data-licenses/) distinguishes CC-BY and CC0. | It is an archive of collections, not a dataset with a common task or split. Inspect each Dandiset's metadata, version, license, and access state. The archive landing page is script-driven; scope was checked against documentation. |
| FALCON / benchmark | Adds session-shift and limited-calibration decoding evaluation. Official [project site](https://snel-repo.github.io/falcon/) explains few-shot/zero-shot adaptation and says submissions can continue indefinitely. The [maintainer repository](https://github.com/snel-repo/falcon-challenge) supplies NWB data links, dataset notebooks, baseline decoders, local minival, and the EvalAI/Docker interface; code is MIT licensed. | Some evaluation data are withheld. Remote submission requires an EvalAI team and container setup; the README notes possible submission-environment incompatibility. Website statements were verified, but the authenticated EvalAI workflow and current server operability were not tested. |
| SENSORIUM / benchmark family | Adds neural encoding tasks with explicit stimulus/response pairs. Official [site](https://sensorium-competition.net/) distinguishes 2022 images from 2023 videos and links data, starter kits, and results. The [2023 maintainer repository](https://github.com/ecker-lab/sensorium_2023) documents data, model, and training notebooks plus the October 2023 deadline. | Historical competition deadlines have elapsed. The [requirements file](https://github.com/ecker-lab/sensorium_2023/blob/main/requirements.txt) pins several older dependencies; reuse requires environment review. No repository license was identified in the inspected 2023 root listing, so no general code-reuse license claim is made. Current remote evaluation and complete download licenses were not tested. |

## Community additions and primary evidence

| Resource / type | Why include it and what was verified | Access and currency notes |
| --- | --- | --- |
| CCN / conference | A direct venue for cognition, computational models, and neuroscience. The official [canonical site](https://ccneuro.org/) redirects to the 2026 edition and exposes papers, keynotes/tutorials, community events, and past editions. | The canonical URL keeps the entry useful beyond one year. Programs can guide reading; attendance and submissions have edition-specific registration and deadlines. No registration was attempted. |
| COSYNE / conference | Supplies the empirical/theoretical systems-neuroscience context needed to evaluate NeuroAI claims. Its official [site](https://www.cosyne.org/) lists tutorials, workshops, past meetings, and the current 2027 calls. | Dates are intentionally not copied into the evergreen entry. Readers should inspect the current edition and participation conditions. No submission or attendance availability is promised. |
| Brain Inspired / podcast and discussion community | Provides research conversations approachable before reading a full technical paper. The official [site](https://braininspired.co/) links episodes, describes the neuroscience/AI scope, and advertises full episodes/archive and Discord as support benefits. | Public episode material does not imply unrestricted access to every episode or community channel. The entry makes the supporter distinction and does not present interviews as primary scientific evidence. |

## Checks and unresolved evidence

The existing resource lines were compared with the original Git versions, and local section anchors were retained. No additions duplicate the original resources on these two pages. Source URLs were opened during review; successful page access alone is not a reproduction or a runtime check.

Remote benchmark submission operability, notebook compatibility, full dataset download terms, and event registration availability remain outside this documentation review. SENSORIUM's inspected repository did not provide an obvious root license; its code-license status remains unresolved. These limits are reflected in the resource descriptions rather than concealed behind an installation or performance claim.
