# Learning-resource expansion: 2026-10-11

## Selection

The additions address three gaps in the initial collection: preparation for readers with little coding or neuroscience background, deeper reference material for readers beyond introductory courses, and small documented exercises before research-scale work. Stage assignments and learning routes are editorial suggestions.

| Addition and primary source | Verified scope and reason for inclusion | Access and verification boundary |
| --- | --- | --- |
| [Python NumPy Tutorial](https://cs231n.github.io/python-numpy-tutorial/) | Official Stanford CS231n tutorial covering Python, arrays, plotting, and notebooks; provides the coding preparation used in the foundation route. | Public page and notebook links reviewed; code was not executed. |
| [Mathematics for Machine Learning](https://mml-book.com/) | Author site lists linear algebra, vector calculus, probability, and optimization and offers a free PDF; supplies mathematical prerequisites. | Site requests this domain as its preferred link and redirects to its GitHub Pages site. |
| [Probabilistic Machine Learning: An Introduction](https://probml.github.io/pml-book/book1.html) | Author page identifies the 2022 book and links a draft, exercises, and figure code; provides a deeper modeling reference. | Draft access is free under its stated license; code was not run. |
| [Brain Facts](https://www.brainfacts.org/book) | Society for Neuroscience primer for general readers and students; supplies an entry before mathematical neural modeling. | Official page provides digital editions; this entry does not claim a new edition or clinical applicability. |
| [Neuronal Dynamics](https://neuronaldynamics.epfl.ch/online/) | Official online textbook covers neurons, networks, learning, and cognition; links biological concepts with mathematical models. | Free online text; no claim to have completed its exercises. |
| [Theoretical Neuroscience](https://www.gatsby.ucl.ac.uk/~dayan/book/) | Author page describes neural coding, neuron and circuit models, plasticity, and learning; a deeper reference for advancing readers. | Author page offers exercises and a sample chapter, not unrestricted full-book access. |
| [Dive into Deep Learning](https://d2l.ai/) | Official interactive textbook covers training, optimization, convolutional and recurrent networks; helps neuroscience readers acquire implementation skills. | Public text and code reviewed; framework-specific environments were not installed. |
| [Neuronal Dynamics: Python Exercises](https://neuronaldynamics-exercises.readthedocs.io/en/latest/) | Official companion includes neuron, Hopfield, Hebbian-learning, working-memory, and decision-making exercises; provides bounded modeling tasks. | Documentation and exercise index inspected, without installation or execution. |

These eight resources have their canonical entries in `learn/README.md`. The stage guide links to those sections rather than duplicating entries. No automatic difficulty score or empirical teaching-effectiveness claim is assigned.
